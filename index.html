Remix Studio

A browser-based creative suite with real-time EQ, pitch shifting, and stem separation. Built on a Kotlin DSP engine compiled to WebAssembly.

🎚
Multi-Band EQ
32-band parametric equalizer with real-time preview. Built with Kotlin's DSP pipeline for zero-latency processing.
🎛
Stem Separation
AI-powered vocal, drums, bass, and melody isolation. Remix any individual stem directly in the browser.
🔊
Live Collab
Real-time session sharing via WebSockets. Invite other producers into your session for instant collaboration.

⚙ Kotlin-Powered

Built on
Kotlin

Mixtunel's core — from the audio engine to the data models — is written in Kotlin. The backend runs on Ktor, the frontend logic compiles via Kotlin/JS, and the DSP engine targets Kotlin/Native → WASM.
